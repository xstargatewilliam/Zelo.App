# Política de privacidade do Zelo

**O Zelo não coleta, não guarda fora do seu PC e não envia a ninguém nenhuma informação sua.** Não há telemetria, conta, anúncio nem estatística de uso.

Tudo o que o Zelo registra (histórico, relatórios, log, configurações) fica no próprio PC, em `C:\ProgramData\Zelo`, e só sai de lá se você mesmo copiar e mandar (por exemplo, pelo botão **Copiar** da página Registro).

## Quando o Zelo usa a internet

Só para baixar atualizações, e só o que você deixou ligado em Ajustes:

| Para quê | Com quem | O que é enviado |
|---|---|---|
| Ver se há versão nova do Zelo e baixá-la | GitHub (`github.com`) | Só o pedido da página de versões, como faz um navegador |
| Atualizações do Windows | Windows Update (Microsoft) | O que o próprio Windows Update envia |
| Atualizar programas instalados e instalar os que você escolher na aba Otimizar | winget (Microsoft) e o site de cada programa | O que o próprio winget envia |
| Atualizar as definições do antivírus | Microsoft Defender (Microsoft) | O que o próprio Defender envia |

Os links de suporte de fabricantes (drivers) só abrem no navegador se você clicar neles.

Cada uma dessas atualizações pode ser desligada em **Ajustes → Atualizações**.
