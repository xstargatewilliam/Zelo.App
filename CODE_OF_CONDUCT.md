# Código de conduta

O Zelo segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Em resumo: trate todo mundo com respeito, sem assédio, ataques pessoais ou discriminação, em issues, pull requests e qualquer espaço do projeto. Problemas de conduta podem ser informados ao mantenedor, [William Stargate (@xstargatewilliam)](https://github.com/xstargatewilliam), por mensagem no GitHub.
